🍽️ Restaurant Management Website

A web-based restaurant project developed using PHP, HTML, CSS, and MySQL. The project provides a simple and user-friendly interface for displaying restaurant information, food items, services, contact details, and user registration.

📌 Project Overview

The Restaurant Management Website is designed to provide an attractive online restaurant interface where users can explore food items, view restaurant information, access services, and register through a web-based form.

This project was developed as a practical web development project to understand frontend design, PHP server-side programming, and database connectivity.

✨ Features

- 🏠 Restaurant home page
- 🍔 Food item display
- 📖 About restaurant section
- 🛎️ Restaurant services section
- 📞 Contact page
- 📝 User registration form
- 🔗 PHP database connectivity
- 🎨 Custom CSS styling
- 🖼️ Food images
- 📱 Simple and user-friendly web interface

🖥️ How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the project into:

C:\xampp\htdocs\

4. Open your browser.
5. Enter:

http://localhost:8080/restaurants_project/

6. Configure the database connection in "connect.php" if required.
7. Import the required database into phpMyAdmin if your project uses a MySQL database.
